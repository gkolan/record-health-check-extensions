## Acceptance rule

A release is not accepted merely because the visible demo works. The complete gate requires:

1. All applicable demo rows match the guide.
2. The publication NONE control creates no row.
3. The viewer persona remains read-only.
4. Focused Apex and LWC Jest suites pass.
5. Salesforce Code Analyzer has zero Recommended findings at every severity.
6. A promoted 2GP version installs into an org containing only the promoted core dependency.

If Email is intentionally not tested, record that exception and test its service path in Apex. Do
not report mailbox receipt as guaranteed delivery; DELIVERED means Salesforce accepted the attempt.
