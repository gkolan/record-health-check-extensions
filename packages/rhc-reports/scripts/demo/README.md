# RHC Reports sandbox demo scripts

These scripts create the reusable Opportunity Close Readiness demonstration and acceptance data.
Run them only in a sandbox, scratch org, or disposable demo org.

Do not execute a script until you have read the complete
[demo data and functional test](../../docs/DEMO_TEST_DATA.md). That guide provides the required
order, exact clicks, expected counts, asynchronous wait points, acceptance table, and cleanup
warnings.

The creation, publishing, and snapshot-seeding scripts are safe to rerun using stable identities.
Files whose names begin with `cleanup-` are irreversible and deliberately separate.
